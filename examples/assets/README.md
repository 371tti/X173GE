# Example assets

`aloe_farm_shade_house_1k.hdr` is the 1K Radiance HDR download of Poly Haven's
[Aloe Farm Shade House](https://polyhaven.com/a/aloe_farm_shade_house), used as
the viewer's replaceable diffuse global-lighting environment. Environment-map
specular reflection is disabled; SSR supplies scene reflections. Poly Haven
marks the asset CC0; the original file is 1,762,844 bytes (MD5
`16988bda4f294749b6fecb2370b104b0`). It is a similar greenhouse environment,
not a capture of `../rebuild1/assets/model.glb`.
